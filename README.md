# Puddle-Splash Pals

A laughing child and a golden retriever puppy splash through a sunlit puddle, caught together in a bright burst of water and joy.

## Run it

Use Node 22 with no additional packages:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the bundled image unchanged to `entry.png` in the output directory. When `MAKEFUN_OUTPUT_DIR` is unset, it uses `/output`. The source image is resolved beside `main.ts`, so the program also works when launched from another directory.
